Code for running BioGeoBEARS, slightly modified from code by Nicholas J. Matzke (GPL-3 license) at http://phylo.wikidot.com/biogeobears#script. Note that the package MultinomialCI has been removed from CRAN/R and has difficulty properly loading. BioGeoBEARS still seems able to run without it on Windows machines, but BioGeoBEARS will not compile or install properly without it.
